1. Create a GitHub repo named `ghostchat` and push these four files.
2. In Vercel, choose **Add New Project** and import `ghostchat`.
3. Set Framework Preset to **Other**, leave Build Command empty, and set Output Directory to `.`.
4. Deploy. The site will be available at `ghostchat.vercel.app` or your chosen project domain.
5. No environment variables, backend, or database are required.
